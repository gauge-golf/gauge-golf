# Gauge Golf

Built in public.

A universal performance golf glove designed for grip, wrist stability and high-volume practice sessions.

## About

Gauge Golf documents the process of building a golf product from scratch across driving ranges, factories and field tests in Asia.

The project is currently being developed publicly through a 66-day build challenge leading to the first production batch.

## Stack

* Next.js
* Vercel
* Neon PostgreSQL
* Mobile-first design
